# Training Program — Football Longevity Build (v6)

**Profile:** 38yo · 171cm · ~83kg · strong legs, solid muscle, fat is the limiter
**Goal:** lose ~3–4kg fat (keep muscle), build football engine, protect the knee, look leaner
**Reality:** 2 gym sessions/week (60–90min) · Monday football · sometimes Thursday futsal · 6–7h sleep

> **New in v6:** All main-lift form videos added. (Only the rotating slot-3 core options still need clips.)

---

## Tier system — read this for short days

- **[T1] = always do.** Even on a 50-minute crunch day. The main lift + the protective/medical work.
- **[T2] = skip first when you're short on time.** Valuable, but not essential on any single day.

**Rules:** Never shorten rest on the Tier-1 heavy lifts to save time — drop Tier-2 work instead. The **Core Finisher is Tier 1 and never gets cut** (~7 min). A 50-min day = do the Tier-1 items, skip the Tier-2 ones.

---

## How the cycle works

7–10 day cycle. The 2 gym slots = **Session A + (B or C)**. A every cycle.

- **Futsal week → do C** (matches cover legs).
- **No futsal week → do B** (or C if feeling heavy / pushing fat loss).

**Hard rules:**
1. **Every gym session = Athletic Prep → main work → Core Finisher.**
2. Never do **B within 48h** of a match.
3. Never stack two hard leg loads back-to-back.
4. **Don't let two futsal weeks in a row pass without loading your legs.** If it happens, append to a C session: Squat 2×5 + RDL 2×8.

---

## How to load & how hard to push

**Warm up the heavy lifts (doesn't count toward your sets).** Empty bar, then progressively heavier ramp sets. Non-negotiable for the squat.

**Straight sets — same weight across all working sets.** "Bench 4×5–6" = one load for ~5–6 reps, four times, with a little left on the last set.

**Leave reps in the tank — NOT to failure on the big lifts.** Stop bench / squat / RDL with ~2–3 good reps still possible.

**Where you CAN push:** last set of isolation work (curls, triceps, leg curl, calf). Accessories: 1–2 reps in reserve.

**Starting weight:** week 1 is calibration. Err light.

**Double progression:** top of the rep range on all sets, good form, reps in reserve → add ~2.5kg upper / 2.5–5kg lower.

**Fat-loss phase:** lifting protects muscle, not records. Holding your numbers steady is a WIN.

## Session A — Upper + Pull Balance

*Low leg demand → safe close to matches. Every cycle.*

**[T1] 1. Barbell Bench Press** — 4 × 5–6 · rest 2–3 min · leave 2–3 in reserve · [▶ video](https://www.youtube.com/shorts/_FkbD0FhgVE)
> Shoulder blades back and down, feet planted, control the descent. Your strength lift.

**[T2] 2. Pull-up or Lat Pulldown** — 3 × 8–10 · rest 90s · [▶ video](https://www.youtube.com/shorts/bNmvKpJSWKM)
> Full stretch at top, drive elbows down.

**[T1] 3. Seated Row** — 3 × 10–12 · rest 90s · [▶ video](https://www.youtube.com/shorts/qD1WZ5pSuvk)
> Chest tall, squeeze, no shrugging. The pull that stays — it balances your bench.

**[T2] 4. Seated DB Overhead Press** — 3 × 8–10 · rest 90s · [▶ video](https://www.youtube.com/shorts/k6tzKisR3NY)
> Back supported, dumbbells start at ear height, elbows ~45° (not flared out). Press up and slightly in to overhead, control down. **Don't arch the back / flare the ribs** — brace abs and glutes.

**[T2] 5. Arms superset** — 2–3 rounds, rest 60s · last set near failure OK
> DB Curl 10–12 [▶](https://www.youtube.com/shorts/MKWBV29S6c0) + Cable Triceps Pushdown 10–12 [▶](https://www.youtube.com/shorts/1FjkhpZsaxc). Your "definition" slot. **Cut this first** when short on time.

**→ Core Finisher [T1]**

## Session B — Lower + Power

*Non-futsal weeks only, away from matches.*

**[T1] 1. Back Squat** — 4 × 5–6 · rest 2–3 min · never to failure · [▶ video](https://www.youtube.com/shorts/dW3zj79xfrc)
> Brace, knees track over toes, control to a depth you own. Stays because your knee has 5 years of tolerance. If it complains: front/box squat or leg press before quitting squats.

**[T1] 2. Romanian Deadlift** — 3 × 8 · rest 2 min · leave 2–3 in reserve · [▶ video](https://www.youtube.com/shorts/Wou9zVQrAfs)
> Hips back, soft knees, neutral spine. Posterior chain + hamstrings.

**[T1] 3. Lateral Lunge** — 3 × 8/leg · rest 90s · 1–2 in reserve · [▶ video](https://www.youtube.com/shorts/4UbxJQe4im8)
> Step wide, sit into the working hip, other leg straight. Frontal-plane / adductor / anti-valgus work — T1 over the leg curl.

**[T2] 4. Kettlebell Swing** — 3 × 12 explosive · rest 90s · [▶ video](https://www.youtube.com/shorts/TIy6s4O2bOY)
> Hip snap, not a squat. Skippable on short days — matches give you plenty of explosive hip extension.

**[T2] 5. Leg Curl** — 3 × 10–12 · rest 75s · last set near failure OK · [▶ video](https://www.youtube.com/shorts/_lgE0gPvbik)
> Direct hamstrings. T2 only because the RDL covers them on a short day — stays in the full session.

**[T2] 6. Standing Calf Raise** — 3 × 12–15 · rest 60s · last set near failure OK · [▶ video](https://www.youtube.com/shorts/wdOkFomQNp8)
> Achilles + push-off + deceleration. First to drop with the swing when crunched.

**→ Core Finisher [T1]**

## Session C — Conditioning

*Spinner/rower — knee-friendly. Alternate the two types; NEVER both in one week.*

- **[T1] Warm-up** — 5–8 min easy, build gradually.
- **[T1] Main — alternate each C session:**
  - **Week type 1 — RSA (spinner):** 15s hard / 45s easy × 8–10. *(Optional 2nd round = [T2].)*
  - **Week type 2 — VO₂max (rower/spinner):** 4 min hard / 3 min easy × 4.
- **[T2] Cooldown** — 5 min easy + mobility.

**→ Core Finisher [T1]**

## Core Finisher — ends EVERY gym session · [T1], NEVER cut (~7 min)

*Doctor's priority. 3-slot template; slot 3 rotates so adductor/lateral work shows up every cycle.*

- **Slot 1 — Anti-rotation:** Pallof Press — 2–3 × 10–12/side · [▶ video](https://www.youtube.com/shorts/5aZ0IhJS8O8)
- **Slot 2 — Anti-extension:** Dead Bug [▶](https://www.youtube.com/shorts/DqLL45uk2Tk) *or* Front Plank — 2–3 × 8–10/side or 30–45s
- **Slot 3 — Lateral / adductor (rotate):** Copenhagen Plank *or* Side Plank *or* Suitcase Carry *(add videos)*
> Copenhagen = the adductor piece (start short-lever, progress slowly). Rotate slot 3 session to session.

---

## Progression

- **Strength lifts:** double-progression → add a small load at the top of the range.
- **Core / Copenhagen:** add time/reps → lengthen lever → load.
- **Cardio:** add an interval or hold higher intensity every couple of weeks.

## The honest part

Training keeps your muscle, builds your engine, and protects the knee. It does NOT drive the fat loss — that's the kitchen, outside what I coach. The definition you want is already built; losing the fat reveals it.
